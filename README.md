# Quokka's G-Sound Garden

A bilingual English/Traditional Chinese phonics game for distinguishing Soft G /dʒ/ and Hard G /g/.

Open `dist/index.html` through a local static web server. No build step is required.

## Learning design

- Three levels: Soft G, Hard G, and mixed practice
- Weighted word tiers: core, regular, and occasional challenge words
- English speech synthesis for every word
- First press of a word's audio button extends that turn by three seconds
- Practice mode in the first two levels; lives are used in the mixed level

## Art provenance

Background and characters were generated with built-in OpenAI ImageGen (`host_image`) using the approved Version A visual boards as style and identity references.
